# App Icon Assets

This directory holds the source icon assets used by the app view/action buttons.

- Format: SVG
- Preferred styling: `fill="currentColor"` and/or `stroke="currentColor"` where possible
- Lookup map: `manifest.json`

Notes:
- Runtime icon rendering currently lives in `frontend/src/components/AppButtonIcon.jsx`.
- The files here are the canonical asset set so all button glyphs are in one place and can be edited consistently.
