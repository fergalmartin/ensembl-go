# Notes

Notes collects observations about genes, genomic locations and genomes, together with general project notes and Todo tasks. Search and tags help you return to work that needs further investigation.

## Before you start

Set an output directory for saved records. For a note linked to a locus, have the relevant genome available locally.

## Using the view

1. In [Genome Browser](GENOME_BROWSER.md), focus a gene or location and use the drawer's **Notes** section to record an observation. Notes are saved as you type.
2. Open Notes to review records across genomes. Create general or genome-level notes, and add Todo tasks to track work.
3. Add tags and use search or tag filters to narrow the list. Update task progress as you work.
4. Use a linked note's navigation control to return to its gene or location. Gene notes also have a speech-bubble marker in the browser when transcripts are visible.
5. Archive records you want to set aside and restore them when needed. Import or export records to retain a copy outside the app or share them.

## Things to know

Notes belong to the assembly, so updating its annotation does not discard them. However, a changed identifier or feature boundary can affect how a note resolves against a newer annotation. Keep enough context in the note to recognise the original observation.

Import and export support JSON, CSV and TSV. JSON preserves tags as a list. CSV and TSV separate tags with a pipe character, so tags containing a pipe cannot be preserved exactly through those formats.

The output directory determines which saved records are available. Use the same workspace when returning to an existing project.
