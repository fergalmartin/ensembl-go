# Configuration

Configuration sets the local workspace and the app's appearance, browsing preferences and shortcuts.

## Before you start

Choose a writable directory with enough space for the genomes and tracks you plan to use. Set it as the **Output Directory** under **Outputs**.

## Using the view

1. Open **Outputs** to set or change the output directory.
2. Use **Save Configuration** to write your settings to a file. Use **Load Configuration** to restore a saved configuration, or **Reset to Defaults** to reset preferences.
3. Open **Organise Apps** to add or remove view and action buttons and arrange their order.
4. Adjust **Colour schemes** and the general browsing settings to suit your workspace.

Genome colours can also be assigned individually in [Genome Selector](GENOME_SELECTOR.md). The Theme Toggle action switches between light and dark themes from the top bar.

## Things to know

The output directory identifies the workspace containing your local catalogue and saved records. Changing it can change which genomes, playlists, notes and registrations are available. Use the same directory when returning to an existing project.

A saved configuration records settings and paths; it does not copy the genome or track files those paths refer to. Those files must still be available when you load it.
