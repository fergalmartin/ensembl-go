# Achievements

Achievements offers optional rewards for exploring Ensembl Go, including less obvious controls and workflows. Some criteria are visible and others are left for you to discover.

## Before you start

Open Achievements from Home, or add its shortcut through **Organise Apps** in Configuration. Set an output directory so progress can be retained with your workspace.

## Using the view

1. Open the view to inspect the numbered collection and anything you have already unlocked.
2. Press **Enable achievements** to switch on the achievement experience.
3. Explore the app and follow progress bars for achievements with several requirements.
4. When an unlock notification appears, hover to keep it open or click it to return to the view. Use the view's controls to turn notifications off if you prefer.

## Things to know

Progress is recorded before you enable achievements, so previously completed actions can already appear as unlocked. The feature is optional and its shortcut is absent from the default bar.

Progress is stored in the output directory alongside other workspace records. Keeping that directory retains progress across application updates or reinstalls.

Ordinary actions performed inside a tutorial do not count towards unrelated achievements. Tutorial achievements track the walkthroughs themselves.
