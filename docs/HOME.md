# Home

Home is the starting point for Ensembl Go. Its cards describe the available views and open them directly.

## Before you start

Set an **Output Directory** in [Configuration](CONFIGURATION.md) when prompted. This is the workspace for downloaded data, indexes and other local records.

## Using the view

1. Read a card's description and click it to open that view.
2. For a first visit, start with [Tutorials](TUTORIALS.md), or follow [Download](DOWNLOAD.md) and [Genome Selector](GENOME_SELECTOR.md) to prepare a genome.
3. Return to Home when you want to explore another part of the app.

The top bar keeps the view shortcuts and selected genomes available as you move between views. Use **Organise Apps** in Configuration to choose which buttons appear and change their order.

## Things to know

A view can be opened from Home even when its shortcut is absent from the top bar. Some views need local data before they can show results; their guides explain those requirements.
