# Tutorials

Tutorials provides guided introductions to Ensembl Go through highlighted controls and short, ordered steps. You can carry out the actions yourself or use Autoplay.

## Before you start

Set an output directory. Tutorials prepare a separate temporary session, often using bundled demo data, so you can learn without replacing your working selection.

## Using the view

1. Start with **Getting Started** for the download, selection and browsing workflow.
2. Choose other available tutorials for genome browsing, multiple genomes, playlists, custom genomes and tracks.
3. Follow the highlighted control and the explanation on each card. Perform the action yourself or use **Next** to let the tutorial perform it where supported.
4. Use **Autoplay** to watch the steps run. Use the section and step controls to revisit part of the walkthrough.
5. Finish or exit the tutorial to return to your previous session and configuration.

The view also provides controls to create or import tutorials and keep drafts in the output directory.

## Things to know

The genomes and settings shown during a tutorial belong to its example session. Return to your normal session before using what you have learned on your own data.

The available tutorial collection can grow as the app develops. Use [Help](HELP.md) or these guides for a short reference when a dedicated walkthrough is not available.
