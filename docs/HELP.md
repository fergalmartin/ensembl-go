# Help

Help provides short explanations of the views and the buttons at the top of Ensembl Go. It is a quick reference while you work in the app.

## Before you start

No genome data are needed to read Help. If you are new to the app, start with its **Getting started** section.

## Using the view

1. Open a section for the view or task you want to understand.
2. Read **What you can do in Ensembl Go** for an overview of genome selection and navigation.
3. Read **Action buttons** for the Genome Playlist, Theme Toggle and Screenshot controls.
4. Go to [Tutorials](TUTORIALS.md) when you want a guided example, or use the [documentation index](README.md) for a fuller written guide.

## Things to know

Most top-bar buttons open views. Genome Playlist changes the selected collection, Theme Toggle changes the appearance, and Screenshot starts capture in a view with an exportable panel.

For a screenshot, choose the part of the view to capture, then its filename, format and directory. Set an output directory in Configuration before exporting.
